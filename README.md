# Featured Projects

### ⚙️ Data Engineering & Machine Learning

**[AnomX — Predictive Maintenance Pipeline](https://github.com/omarnagy122/Anomx)**

• Built an end-to-end predictive maintenance system using the NASA C-MAPSS dataset (160K+ sensor records).

• Implemented Kafka ingestion, PostgreSQL storage, feature engineering, and XGBoost failure-risk predictions.

• Compared Random Forest and XGBoost using an engine-level 70/30 split with 48K+ held-out records.

• Achieved 0.85 Precision, 0.85 F1-score, and 0.99 ROC-AUC; XGBoost achieved 0.85 failure-class recall vs. 0.82 for Random Forest.

• Orchestrated hourly scoring with Apache Airflow and built a Streamlit alerts dashboard.

• Led a 5-member team and validated the pipeline with 28/29 passing pytest tests.

**Stack:** Python, Kafka, PostgreSQL, Airflow, XGBoost, Streamlit, Docker Compose.

### 🤖 NLP & LLM Projects

**[Arabic RAG Question Answering — Wikipedia](https://github.com/omarnagy122/REPLACE-WITH-ARABIC-RAG-REPO)**

• Built an Arabic RAG prototype using LangChain, ChromaDB, and multilingual BAAI/bge-m3 embeddings.

• Processed 127 chunks and implemented Top-5 semantic retrieval over a Wikipedia article.

• Compared Stuff, Map-Reduce, and Refine answer-generation strategies.

• Used grounded prompts and an explicit no-answer fallback; Refine produced more complete answers in qualitative tests involving multiple chunks.

**Stack:** Python, LangChain, ChromaDB, BAAI/bge-m3, Groq API.

**[News Topic Classification — AG News](https://www.kaggle.com/code/omarnagy122/notebook5d29ef87df)**

• Fine-tuned BERT using Hugging Face Transformers and PyTorch.

• Achieved 94.8% accuracy and 94.8% Macro-F1 on the AG News test set.

• Reimplemented training using a manual PyTorch training and evaluation loop, achieving 94.7% accuracy and Macro-F1.

**Stack:** Python, PyTorch, Hugging Face Transformers, Datasets, Tokenizers.
